逐项检查应用内路由的访问保护；绿色表示该项检查通过，不表示登录、保存等完整业务已测试。耗时为服务端检查耗时。

这些数字代表什么？

这是 Nginx 的服务器级连接快照，包含 API、页面、静态资源和健康检查自身的连接。正在读写不等于后台正在执行的 API 数量，也不等于正在做题或在线的人数；HTTP/2 还可能在一个连接内同时发送多个请求。

页面只读取状态，不发起并发测试。快照最多缓存 3 秒；后台标签页暂停自动刷新。数据库检查仅验证读取连通性，不验证每个业务接口或写入成功率。
