# ZYZ IELTS Maple Edited

[![License: GPL-3.0](https://img.shields.io/badge/License-GPL--3.0-blue.svg)](LICENSE)

基于 [IELTS-practice](https://github.com/sallowayma-git/IELTS-practice) 修改的自部署雅思练习网站。项目将阅读、听力练习与个人学习记录整合到同一网站，教师可发布阅读与听力考试、布置写作并逐篇批改，学生可通过精读、精听和写作反馈复盘。

> 本仓库发布程序源码。题目、文章、音频、PDF、翻译数据、真实用户数据库和部署密钥需要由部署者自行准备，未包含在仓库中。

## 功能

| 模块 | 提供的能力 |
| --- | --- |
| 阅读与听力 | 按分类浏览题库、筛选题目、作答、提交批改、查看结果和历史练习 |
| 写作 | 发布班级或个人任务、保存作文草稿、教师批注与分项评分、查看反馈 |
| 套题与考试 | 听力从 Part 1–4 各抽一篇，按顺序交卷并查看整套结果，教师按年级与班级发布限时考试并查看交卷情况 |
| 精读 | 划词查词、生词收录、文章高光与笔记、题目分屏和历史作答查看 |
| 精听 | 原文划词、变速播放、A–B 复听、时间轴和生词管理 |
| 个人数据 | 账号注册登录，按用户独立保存作答、正确率、笔记和生词 |
| 教师工作台 | 按年级、班级和学生查看学习趋势、题型正确率、逐题表现与作答回放 |
| 维护页面 | 查看服务健康、使用情况及教师操作记录，按权限管理账号 |

部分功能依赖相应题源、音频或翻译文件。缺少这些文件时，相关题目或模块不会有完整内容。

## 与原项目的区别

以下对比以原项目的 **`main` 静态网页版** 为基准。原项目已有阅读练习、可选听力扩展、套题、练习记录、成绩统计、词汇辅助等能力；本项目在这些基础上改造为多人使用的自部署网站。原项目另有服务器版等分支，此表不代表与其全部分支的比较。

| 方面 | 原项目 `main` | 本项目的改动 |
| --- | --- | --- |
| 运行与数据 | 静态页面，学习数据主要保存在浏览器本地 | 增加 Flask 服务与 SQLite 存储，支持账号注册登录、云端保存及每位用户独立的数据 |
| 练习与复盘 | 阅读为主，提供可选听力、套题及本地练习记录 | 整合阅读和听力练习；改进提交、退出、拖拽与移动端交互；按用户保存作答并支持回看 |
| 深度学习 | 提供词汇辅助等基础学习工具 | 增加精读高光与笔记、划词词典、题目分屏；增加精听原文、变速、A–B 复听、时间轴、划词与生词本 |
| 教师使用 | 以个人练习与本地统计为主 | 增加教师工作台，按年级、班级、学生查看阅读和听力表现、题型与逐题统计，并回放作答 |
| 考试管理 | 个人套题练习 | 增加面向班级的限时考试发布、交卷状态与考试专属统计 |
| 运维 | 静态托管即可使用 | 增加账号权限管理、健康与使用情况页面，支持 Nginx 静态资源和 Gunicorn 服务部署 |

### 重点优化

- **多人使用**：账号之间隔离作答、笔记和生词；教师视图按班级与个人组织数据。
- **学习体验**：统一阅读与听力的练习界面和题型交互，增加加载与提交状态、作答回放、笔记和精听工具。
- **可靠性与性能**：针对 Safari 弹窗限制提供当前页练习和独立交卷路径；交卷失败可按同一提交编号安全重试；题库列表分批加载，并支持由 Nginx 直接提供静态资源。实际并发能力取决于部署配置和服务器资源。

### 开发演进摘要

- **练习闭环**：完善拖拽落点反馈、提交与退出确认、套题成绩换算，以及保存成功后的结果查看。
- **教师与考试**：增加只读作答回放、阅读与听力逐题统计、班级考试发布和仅针对该场考试的数据图。
- **精读与精听**：精读加入长句笔记与题目分屏；精听加入逐句时间轴校准、原文译文、划词词典和账号独立的生词管理。
- **线上运行**：完善加载状态、诊断信息与健康检查，优化服务进程和 SQLite 等待设置，减少慢加载与重复提交造成的困扰。

本公开仓库仅发布程序源码，不附带原项目或第三方题库素材；部署后需要自行配置有权使用的内容。

## 技术结构

- 前端使用原生 HTML、CSS 和 JavaScript。`scripts/build-bundles.mjs` 生成运行时 bundle。
- 服务端使用 Python Flask，学习数据由 SQLite 保存。
- 生产部署可使用 Gunicorn 运行 Flask，再由 Nginx 提供 HTTPS 和静态文件。

```text
.
├── index.html               # 网站入口
├── css/                     # 页面样式
├── js/                      # 前端逻辑和运行时 bundle
├── server/                  # Flask 接口、账号、教师统计与考试管理
├── scripts/                 # 前端构建脚本
├── templates/               # 练习页面模板
└── assets/generated/        # 只保留通用练习页面；题库内容未发布
```

## 快速开始

需要 Python 3、Node.js（仅在重建前端 bundle 时需要）和自行取得授权的题库文件。以下示例在 Linux 或 macOS 的终端运行。Windows 可用 PowerShell 设置相同的环境变量。

```bash
git clone https://github.com/Minurr/ZYZ-IELTS-Maple-Edited.git
cd ZYZ-IELTS-Maple-Edited
python3 -m venv .venv
. .venv/bin/activate
python -m pip install Flask

export IELTS_SECRET="$(python -c 'import secrets; print(secrets.token_urlsafe(48))')"
export IELTS_ACCESS_PASSWORD="请设置自己的访问密码"
export IELTS_DATA="$HOME/.local/share/zyz-ielts"
export IELTS_ORIGIN="http://127.0.0.1:8000"
export IELTS_SECURE="false"

cd server
python -m flask --app app run --host 127.0.0.1 --port 8000
```

启动后访问 `http://127.0.0.1:8000`。首次访问需要输入你设置的访问密码。公开部署时，请改用 HTTPS，将 `IELTS_ORIGIN` 设为网站的实际来源，并将 `IELTS_SECURE` 设为 `true`。

前端 bundle 已随源码发布。修改前端源码后，可在仓库根目录运行 `node scripts/build-bundles.mjs` 重新生成 bundle。

### 环境变量

| 变量 | 用途 |
| --- | --- |
| `IELTS_SECRET` | 签名密钥，必须自行生成并妥善保存 |
| `IELTS_ACCESS_PASSWORD` | 网站首次访问的入口密码，必须自行设置 |
| `IELTS_DATA` | SQLite 数据目录，建议放在仓库之外 |
| `IELTS_ORIGIN` | 网站实际来源，用于请求来源校验 |
| `IELTS_SECURE` | HTTPS 部署设为 `true`，本地 HTTP 开发可设为 `false` |
| `IELTS_ADMIN_ID` / `IELTS_ADMIN_IDS` | 可选，授予指定账号教师及维护权限 |
| `IELTS_TEACHER_AUTH_IDS` | 可进入 `/admin/auth` 的授权人账号 ID，以逗号分隔，默认无人可进入 |
| `IELTS_SITE_OWNER_ID` | 可选，指定站长账号 ID |

账号 ID 由系统注册时生成。不要把真实账号 ID、密码或数据库写入公开仓库。

### 教师授权与审计

1. 将授权人的账号 ID 写入服务端环境变量 `IELTS_TEACHER_AUTH_IDS`，重新加载应用后生效。
2. 授权人登录后打开 `/admin/auth`，勾选一个或多个英语部（`English Dept.`）账号，输入自己的登录密码并提交。系统会重新核对所选账号资格，整批通过后授予教师工作台访问权限。
3. 教师从 `/admindata` 发布考试、布置写作及批改。维护人员在 `/usedata` 查看操作时间、操作人、对象和处理结果，包括授权、发布、撤回、删除及批改操作。

## 部署与题库

生产环境可在仓库根目录运行 `gunicorn --chdir server --bind 127.0.0.1:8000 app:app`，并在 Nginx 中配置 HTTPS、静态文件和到 Gunicorn 的反向代理。请根据自己的服务器和并发需求调整进程数与资源限制。

本仓库没有发布阅读与听力题源。`ReadingPractice/`、`ListeningPractice/`、题库索引、音频、PDF 和翻译数据需要由部署者依据自身授权单独准备。导入听力录音时请核对实际容器格式。对于含 MP3 音轨的 QuickTime 文件，可以无损重新封装为标准 MP3，再更新题页引用，以改善 Safari 的播放兼容性。

代码中的示例学校仅用于展示注册与班级统计流程，可按部署场景修改。

## 数据与安全

- 用户数据保存在 `IELTS_DATA` 指定的目录。备份和迁移时应保护该目录。
- `.gitignore` 排除了常见数据库、密钥、压缩包和题源路径。提交前仍需检查新增文件。
- 公共仓库不提供生产凭据、现有用户数据或服务器配置。
